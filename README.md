Geethayaana 2026 – Event Registration Portal
Geethayaana 2026 is a web-based event registration system developed for our college annual fest to simplify and digitize the registration process.

The platform allows students to log in, explore available events, and register seamlessly without manual paperwork. 
It also provides an admin interface to manage events, monitor registrations, and control portal access.

Key Features :

Student login and event registration
Admin dashboard for event management
Role-based access (Admin / Student)
Real-time registration handling
Responsive design for mobile and desktop
Portal open/close control by super admin

Purpose :
The project was designed to eliminate manual registration challenges such as delays, data errors, and lack of centralized tracking. 
It improves efficiency, accuracy, and user experience.

Real-world Impact :
This system was actively used during our college fest, handling real-time registrations and receiving positive feedback from both students and faculty for its simplicity and effectiveness.
