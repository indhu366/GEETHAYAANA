# Geethayaana 2026 – Event Registration Portal

## Overview

Geethayaana 2026 is a web-based event registration system developed for our college annual fest to simplify and digitize the registration process.

The platform allows students to log in, explore available events, and register seamlessly without manual paperwork. It also provides an admin interface to manage events, monitor registrations, and control portal access efficiently.


## Key Features

• Student login and event registration  
• Admin dashboard for event management  
• Role-based access control (Admin / Student)  
• Real-time registration handling  
• Responsive design for mobile and desktop devices  
• Portal open/close control by Super Admin  


## Purpose of the Project

The project was designed to eliminate challenges associated with manual event registrations, such as:

• Registration delays  
• Data entry errors  
• Lack of centralized tracking  
• Inefficient management process  

This system improves efficiency, accuracy, and overall user experience for both students and administrators.


## Real-World Impact

This is not just a demo project — the system was actively used during our college fest for handling real-time event registrations.

The platform successfully managed multiple registrations and received positive feedback from both students and faculty for its simplicity, speed, and effectiveness.


## Live Project

The project is currently deployed and actively used in our college environment.
